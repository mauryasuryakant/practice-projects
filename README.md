This is a place where I put all of my practice projects specially from React.

## Projects (folders)
- LS_ContextAPI-Project
- RHF-Validation-Project

## Quick start
1. Clone the repository:
   ```bash
   git clone https://github.com/mauryasuryakant/practice-projects.git
   ```
2. Change into the project folder you want to work on:
   ```bash
   cd practice-projects/<project-folder>
   ```
3. Follow the README inside that folder for project-specific setup and run instructions.
